# Phase 8 – Project Demonstration

## Description

This phase presents the working PocketSmart AI application and demonstrates the complete user flow from opening the application to generating and reviewing recommendations.

## Demonstration Flow

1. Open PocketSmart AI landing page.
2. Register a new user.
3. Sign in.
4. Open the dashboard.
5. Select Home Planner and enter budget/preferences.
6. Generate and review the Home recommendation.
7. Select Party Planner and generate a party budget plan.
8. Select Jewelry Planner, enter occasion/style, optionally upload an outfit image, and generate recommendations.
9. Open recommendation history.
10. View full recommendation details.
11. Demonstrate shopping links and print/save functionality.
