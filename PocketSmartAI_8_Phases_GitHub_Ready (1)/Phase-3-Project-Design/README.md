# Phase 3 – Project Design

## Description

This phase defines the architecture, user flow, module structure, interface design, and data flow of PocketSmart AI.

## Architecture

**Browser/UI → Flask Application → Planner Module → Budget/Recommendation Logic → Gemini AI (optional) → Result & History**

## Main Modules

1. Authentication Module
2. Dashboard Module
3. Home Planner Module
4. Party Planner Module
5. Jewelry Planner Module
6. AI Recommendation Module
7. History Module
8. UI/Styling Module

## Interface Design

- Professional blue-themed navigation.
- Landing page with features, testimonials, and call-to-action.
- Card-based dashboard.
- Form-based planner pages.
- Structured recommendation result pages.
- Responsive styling for different screen sizes.

## Outcome

The application structure and screen flow were designed before coding.
