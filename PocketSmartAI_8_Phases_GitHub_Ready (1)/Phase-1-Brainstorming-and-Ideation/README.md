# Phase 1 – Brainstorming and Ideation

## Description

This phase identifies the problem, target users, project idea, and major features of PocketSmart AI. The idea is to provide one smart budgeting assistant for everyday spending decisions instead of requiring users to manually compare expenses and recommendations.

## Key Points

- Identify the need for personalized budget planning.
- Define PocketSmart AI as a smart budgeting assistant.
- Identify three planning domains: home interior, party, and jewelry.
- Consider AI-generated recommendations based on budget and user preferences.
- Include practical shopping suggestions and budget awareness.
- Consider image-based outfit analysis for jewelry recommendations.

## Outcome

A clear project concept and feature list were established for further requirement analysis.
