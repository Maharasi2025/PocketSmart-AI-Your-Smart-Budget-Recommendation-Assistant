# Phase 2 – Requirement Analysis

## Description

This phase converts the project idea into functional and non-functional requirements for PocketSmart AI.

## Functional Requirements

- User registration and login.
- Dashboard for accessing planners.
- Home Interior Budget Planner.
- Party Budget Planner.
- Jewelry Budget Planner.
- Budget-based recommendation generation.
- Optional outfit image upload for jewelry planning.
- Recommendation history and detail viewing.
- Shopping links for recommended items.
- Print/save support for recommendations.
- Gemini API integration for AI-assisted recommendations.

## Non-Functional Requirements

- Simple and responsive user interface.
- Secure handling of passwords and API keys.
- Maintainable Flask project structure.
- Fast form-based interaction.
- Graceful fallback when the external AI service is unavailable.

## Outcome

The functional modules, inputs, outputs, and supporting requirements were defined before implementation.
