# Phase 5 – Project Development

## Description

This phase contains the actual implementation of PocketSmart AI. The complete runnable source code is stored inside the `PocketSmart-AI-Source` folder in this phase.

## Implemented Features

- Flask web application.
- User registration and login.
- SQLite user/recommendation storage.
- Landing page, dashboard, and authentication UI.
- Home Interior Budget Planner.
- Party Budget Planner.
- Jewelry Budget Planner.
- Outfit image upload and preview.
- Budget allocation and recommendation results.
- Gemini AI integration.
- AI/API fallback handling.
- Recommendation history and detail pages.
- Shopping links and print/save option.
- Responsive CSS styling.

## Source Location

`./PocketSmart-AI-Source/`

Run the application from this source folder with:

```bash
python app.py
```
